# Decisions

One file per decision that was not obvious, numbered in the order taken.
Context, the options, what was chosen, and what that costs. A page each.

These exist so that a choice can be revisited on its merits instead of being
rediscovered by accident, and so that the reasoning survives the people who
made it. Write one whenever the answer to "why is it like this?" would
otherwise live only in somebody's memory.
